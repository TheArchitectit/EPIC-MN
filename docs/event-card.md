# 🎟️ Your Journey Card — You're the Boss

> You are the product owner. The AI is your engineer.
> You describe. It asks. It plans. It shows you. Then it builds.

## The 7 phases (say them out loud!)

1. 🧠 **Brainstorm** — "I want an app that…"
2. 📐 **Blueprint** — the spec: *what* it must do
3. 🧱 **Floor plan** — the design: *how* we'll build it
4. ✅ **To-do** — the task checklist
5. 🕵️ **Check** — validation: green checks
6. 🔨 **Build** — watch it come alive
7. 🚀 **Ship** — archive: saved forever

## Your two review gates (never skip them)

- After the blueprint: **"Does this match what I meant?"**
- After the floor plan: **"Is this how we should build it?"**

## Opening lines that work

- "I want an app that helps me ______."
- "Make a website for ______ that feels ______."
- "Build a tool that can ______. Ask me questions to make it real."

## If you're stuck

- Say **"I don't know"** — a guess you can change beats no answer.
- Say **"change X"** — software is built by changing, not by guessing.
