# Zigzag Clubhouse — project

A tiny, local-first web application for a fictional physical clubhouse.

- **App:** one static HTML page (vanilla HTML/CSS/JS), opened directly in a browser.
- **All facts are invented:** venue, members, events, rooms, announcements — no real data, no accounts, no downloads, no online services.
- **Persistence:** in-browser only (localStorage) for user-made changes; demo data is seeded.
- **Vibe:** playful & creative — colorful, expressive, fun.
- **Delivery:** OpenSpec-style specs under `openspec/specs/`; changes tracked in `planned-changes/` and `changelog.md`.
